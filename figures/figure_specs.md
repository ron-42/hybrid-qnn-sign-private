# Figure Specifications

## fig:evaluation-logic

- **Class / role:** concept-method / motivation overview.
- **Core conclusion:** evaluation risks must be paired with controls before
  attributing a result to QCA.
- **Hero evidence:** three risk-to-control pathways converging on a bounded
  claim.
- **Layout / backend:** converging horizontal paths / deterministic TikZ.
- **Source:** `paper/figures/fair_evaluation.tex`.
- **Evidence status:** illustrative-only.
- **Reviewer risk:** readers could mistake the controls for guarantees; the
  caption states that they narrow rather than prove causal attribution.

## fig:qca-overview

- **Class / role:** concept-method / overview.
- **Core conclusion:** the only quantum computation is an eight-dimensional
  bottleneck that produces channel gates for classical DenseNet features.
- **Hero evidence:** exact data-flow and dimensionality.
- **Supporting evidence:** classical/quantum color separation and feature
  bypass into multiplication.
- **Entities:** input image, DenseNet121, pooling, projection, angle embedding,
  variational circuit, measurement, sigmoid gate, classifier.
- **Relationships:** left-to-right data flow plus a feature bypass.
- **Layout:** horizontal pipeline.
- **Backend:** standalone TikZ to preserve exact dimensions, operators, and
  readable labels in a self-contained paper package.
- **Source / backup:** `paper/figures/qca_overview.tex`; prose fallback.
- **Evidence status:** illustrative-only, with dimensions checked against code.
- **Reviewer risk:** diagram could be misread as quantum feature extraction;
  caption must state that DenseNet remains classical.

## fig:controls

- **Class / role:** concept-method / control overview.
- **Core conclusion:** model comparisons differ only in the channel
  transformation between shared features and classifier.
- **Hero evidence:** four branches from one feature node into one head.
- **Layout / backend:** branch-and-merge / deterministic TikZ.
- **Source:** `paper/figures/control_comparison.tex`.
- **Evidence status:** illustrative-only, checked against model code.
- **Reviewer risk:** parameter counts are intentionally left to Table 1 to
  prevent a crowded diagram.

## fig:evidence-ladder

- **Class / role:** concept-method / interpretation guide.
- **Core conclusion:** the three studies support progressively stronger but
  still bounded forms of evidence.
- **Hero evidence:** ascending sanity, attribution, and generalization levels.
- **Layout / backend:** vertical ladder / deterministic TikZ.
- **Source:** `paper/figures/evidence_ladder.tex`.
- **Evidence status:** illustrative-only.
- **Reviewer risk:** ``stronger'' does not mean conclusive; manuscript
  limitations retain the one-seed and five-signer caveats.

## fig:low-data

- **Class / role:** evidence-result / result-summary.
- **Core conclusion:** SE leads at every training fraction.
- **Hero evidence:** mean test-accuracy curves.
- **Supporting evidence:** sample-SD error bars across three seeds.
- **Layout / backend:** line plot / deterministic matplotlib.
- **Source:** `runs/low_data_summary.csv`.
- **Evidence status:** exact-data.
- **Reviewer risk:** frozen backbone limits deployment interpretation.

## fig:signer

- **Class / role:** evidence-result / failure-analysis.
- **Core conclusion:** between-signer difficulty exceeds method differences.
- **Hero evidence:** method accuracy per held-out signer.
- **Supporting evidence:** signer sample counts in the per-signer table.
- **Layout / backend:** grouped bars / deterministic matplotlib.
- **Source:** `runs/mu_loso_results.csv`.
- **Evidence status:** exact-data.
- **Reviewer risk:** one seed and five signers limit inferential power.

## fig:confusions

- **Class / role:** evidence-result / failure-analysis.
- **Core conclusion:** compared methods have similar pooled class-confusion
  patterns.
- **Hero evidence:** row-normalized confusion matrices.
- **Layout / backend:** four-panel heatmap / deterministic matplotlib.
- **Source:** per-fold prediction CSVs generated by the MU trainer.
- **Evidence status:** exact-data.
- **Reviewer risk:** pooling hides signer-level differences.
